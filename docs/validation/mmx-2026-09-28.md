## Changes and migration

- Balanced interpreter entry now requires an explicit indirect-jump flag.
  Address equality cannot classify mirrored jumps or ordinary continuations.
  Older generated five-argument calls must be regenerated; there is no legacy
  guessing path. The journal records the actual jump PC and resolved target.
- `--historical-profile-manifest` reconciles prior checkpoints independently
  of current captures. Each input passes ROM/module and candidate checks.
  Only analysis seeds/exclusions carry forward, never merged cost or completion
  claims across builds. V1 still needs explicit verified-ROM association.
- Documented LoROM mirrors fold into one analysis seed; SA-1/HiROM do not.
  This removes inflated coverage counts and redundant generated bodies.
- MMX accepts `MMX_GEN_DIR` for isolated control/candidate builds.

Validation: 502 Python tests and 134 actual interpreter bridge checks passed.
The capture tests inspect emitted journal records, including mirrored jump
destinations and ordinary continuations. Historical-input tests reject wrong
ROMs/modules and retain failure exclusions across separately read captures.

The remaining captured fallbacks chiefly have truncated continuations,
unproven callee exit modes or unstable exit facts. Re-observing their addresses
does not establish those proofs. Improving that analysis, then validating the
resulting execution, is the next useful compiler work; blanket promotion would
not be justified by these logs.
